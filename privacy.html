义乌市仵隽网络科技有限公司（以下简称"我们"）运营选品侠（Product Hunter）Chrome 浏览器扩展及其配套服务。我们深知个人信息对您的重要性，并会以高度严谨的方式对待您的信息安全。本隐私政策将帮助您了解：我们收集哪些信息、我们如何使用和保护这些信息、您拥有的权利。

一、我们收集哪些信息

1. 您主动提供的信息

  • 账号信息：当您注册账号时，我们收集您的电子邮箱地址、设备指纹标识（Device ID），用于实现一机一号并发送登录验证码。
  • 联系信息：当您通过客服邮箱（2761373261@qq.com）联系我们时，您主动提供的邮件内容和联系方式。
  • 付款信息：付费升级由 landing-page（https://product-hunter.cn）跳转至微信支付 / 支付宝 / PayPal 官方页面完成，我们不会存储您的银行卡号或支付密码，仅在后端记录支付成功后的订单号、金额、对应套餐用于激活订阅。

2. 插件运行时自动收集的信息

  • 商品页面数据：仅当您主动在 Amazon / eBay / AliExpress / 1688 / Walmart / Temu / Lazada / Shopee / TikTok Shop / SHEIN / Shopify 等支持的电商平台商品页上点击"分析"、"采集"、"关注价格"、"收藏供应商"或"批量分析"按钮时，插件才会抓取当前商品页面 DOM 中的公开信息（商品标题、价格、BSR、评论数、评分、图片链接、规格、供应商名称、offerId 等），上传至后端数据库用于 AI 分析、竞品监控和 1688 找货匹配。
  • 访问记录：后端会记录每次 API 请求的用户 ID、URL、时间戳、源 IP 地址，用于限流（验证码 60 秒 1 次 / 每日 10 次 / IP 10 次每小时）、配额扣减（AI 功能）、安全审计与故障排查。
  • 用户活动日志：插件会记录您在插件面板上的点击事件（功能调用类型、调用时间），用于功能配额统计（如 AI 洞察次数扣减、选品分析用量统计）及产品体验优化。

3. 我们不收集的信息

  • 我们不会在后台持续监听或记录您的浏览器历史记录，也不会读取任何非目标电商平台域名（Amazon / eBay / 1688 等白名单之外）的页面内容。
  • 我们不会收集您的银行卡号、支付密码、身份证号、手机号短信等敏感个人信息。
  • 我们不会出售、出租或交换您的任何个人信息给第三方。

二、我们如何使用收集的信息

  1. 提供并维护选品侠的核心功能，包括商品数据透视、利润测算、竞品监控、AI 洞察、1688 找货匹配等。
  2. 账号注册与安全验证：邮箱验证码登录、Device ID 一机一号防刷、会话鉴权。
  3. 配额管理与扣费：按套餐（Free / Standard / Pro / Enterprise）或 Credits 包统计功能使用次数。
  4. 订阅激活与续费：支付成功后自动激活对应套餐、到期前发送续费提醒邮件。
  5. 通知推送：竞品价格下降提醒、插件版本更新通知、AI 分析报告完成通知（仅在您主动订阅或关注的事件触发）。
  6. 产品改进：基于匿名聚合的使用数据分析用户偏好，优化功能与体验。
  7. 合规与安全：响应监管要求、预防欺诈与滥用、保障平台与账号安全。

三、信息的存储与安全

  • 您的账号信息与业务数据存储在云服务提供商提供的安全数据库中，位于境内并按法规要求做数据备份。
  • 登录凭证采用 JWT（JSON Web Token），生产环境 JWT_SECRET ≥ 32 字符，所有 API 通信均使用 HTTPS（TLS 1.2+）加密传输。
  • 用户密码不存储在我们系统（采用邮箱验证码登录，无密码）；支付信息由微信支付 / 支付宝 / PayPal 三家持牌支付机构直接处理，符合 PCI-DSS 要求。
  • 我们采取访问控制、数据加密、安全审计、定期渗透测试等措施保护您的个人信息；但互联网环境并非 100% 安全，我们会尽力但不保证绝对安全。

四、信息的共享与披露

除以下情形外，我们不会向任何第三方共享您的个人信息：

  1. 取得您的明示同意：例如您主动要求我们提供某个第三方功能。
  2. 服务提供商：仅与为我们提供基础设施（如云服务器、邮件服务、支付机构）且签署保密协议的必要服务提供商共享，这些提供商无权将数据用于自身目的。
  3. 法定情形：法律法规要求、行政或司法机关依法要求披露时。

我们绝不会为了营销目的将您的个人信息出售、出租或与广告商共享。

五、您的权利

  1. 知情权与访问权：您可以随时通过插件设置页或发送邮件至 2761373261@qq.com 申请获取我们持有的您的个人信息副本。
  2. 更正权：如果您认为我们保存的您的信息不准确或不完整，您可以随时联系我们更正。
  3. 删除权（"被遗忘权"）：在符合法定条件下，您可以向我们请求删除您的全部或部分个人信息（含采集的商品记录、会话、订阅），我们会在收到请求后 15 个工作日内处理完毕。
  4. 撤回同意：您可以随时在 Chrome 的扩展管理页面移除选品侠插件并注销账号。注销后除法律法规要求保留的最小必要数据外，其他信息将在 30 天内彻底删除或匿名化处理。
  5. 注销账号：在插件 options 页面或发送邮件至 2761373261@qq.com 申请，我们会在核实身份后 3 个工作日内完成注销。
  6. 投诉举报：如您认为我们处理您的个人信息违反了适用的法律法规，您可以向主管部门投诉举报，也可以直接联系我们。

六、Cookies 与本地存储

  • 插件使用 Chrome Storage API（chrome.storage.local / chrome.storage.session）在本地保存：登录 Token、Device ID、1688 采集缓存、竞品监控列表、用户偏好设置、AI 副驾会话草稿、功能使用次数配额计数。这些数据默认只在您的本机，不会上传，部分同步功能会在您开启时主动上传。
  • Landing-page（https://product-hunter.cn）使用最小必要的 Cookie 来维持登录会话与风控校验，不会用于跨站追踪。

七、儿童隐私

选品侠面向的是跨境电商从业的成人用户，我们不会故意收集未满 14 周岁儿童的任何个人信息。如您发现我们不慎收集了未成年人信息，请立即联系我们，我们会第一时间删除。

八、隐私政策的更新

我们可能会不定期更新本隐私政策（例如因业务功能变化或法律要求变更）。更新后的政策将发布在本页面并更新"最近更新"日期；对于重大变更，我们还会通过登录弹窗或邮件通知您。请您定期查看本页面以了解最新版本。
